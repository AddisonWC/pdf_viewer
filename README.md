This is a PDF viewer designed and vibe-coded by Addison Wimber Cartmell using Anthropic and Openai models.<br>
It has lots of features he wanted and uses regularly, for instance the multi-page scrolling design, the drag-to-zoom, the automatic content crop, and the browser-like link following.<br>
It is his primary PDF viewer.  He mostly reads math.

This file and FEATURES.md are the only files Addison wrote entirely.<br>
Addison mostly doesn't read the code, but he has made lots of important program design choices.  Some of these are optimizations to make reading smoother and keep the renders sharp.<br>
The program is very focused and lacks many features others might expect a PDF viewer to have.<br>

The program is being shared with some of Addison's colleagues; they might make changes for their own use.<br>
They might sometimes push them; we'll see.

Press control+h to learn about the program and customize.<br>
There is AI-generated documentation in /docs
