# Core program features

## Content cropping
The program can autocrop to the content of a given page.
Crop region is shared across pages.
You can also box-drag to crop, which is essentially a zoom feature.

## Arbitrary page tiling
You can create an arbitrary MxN grid of pages, and scroll through it one page at a time.
Most other pdf viewers force you to scroll multiple pages, which makes it awkward to look at specific sets of pages simultaneously.

## Browser-like link following
You can follow hyperlinks in the text with center-click to open a new window, just like a web browser.
You can also follow hyperlinks _into the browser_, for instance to the google scholar entry for a given reference.

## Ask agent
You can feed the current pdf into a CLI AI agent to ask it questions (e.g. "where is this symbol defined").
This is pretty slow and I don't use it as much as I thought I might.
The choice of terminal and CLI program is yours.
