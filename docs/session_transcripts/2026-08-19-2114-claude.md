## Pushing to GitHub

`gh` isn't installed here, so the browser route is simplest:

1. Go to https://github.com/new → name it `pdf_viewer` (or whatever), **don't** check "Add a README/.gitignore/license" — you already have them. Public or private, your call.
2. Then, from this directory:

```bash
git remote add origin git@github.com:<your-username>/pdf_viewer.git
git push -u origin main
```

If you don't have SSH keys on GitHub, use HTTPS instead — `https://github.com/<your-username>/pdf_viewer.git` — and it'll prompt for a personal access token (Settings → Developer settings → Tokens) as the password.

Alternatively install the CLI and skip the web step: `sudo dnf install gh`, then `! gh auth login` and `gh repo create pdf_viewer --source=. --public --push`.
