## Broader suggestions

- ~~Version ranges or a lock file~~ — **done** 2026-08-19: `requirements.txt`
  carries ranges, with the tested versions and the floors' unverified status
  written out in it.
- ~~Split the module~~ — **done in part** 2026-08-19. The UI-independent half
  became the `viewer` package (`ARCHITECTURE.md` has the map). The suggested
  further split of the window class into rendering/search/crop/UI files was
  **declined**: those areas share one mutable view state — `cells`, `doc`,
  `first_page`, `crop_rect` and the generation counters are each touched by four
  to eight of them — so moving methods to other files would hide that coupling
  rather than remove it. `PixmapCache` came out because it was the one part
  already fully encapsulated. The remaining seams, and what each would cost, are
  under **Open** below.
- Convert the test harness to pytest — **declined**, no live argument for it:
  the hand-rolled suite is deterministic, documented in `GOTCHAS.md`, and was
  the safety net for the split. The *cases* it asked for are covered: encrypted
  PDFs (`test_encrypted_pdf_unlocks_everywhere`), platform selection
  (`test_wayland_only_requested_in_a_wayland_session`) and copy-window zoom
  state (`test_copy_window_inherits_crop`) already existed; async cancellation
  gained `test_stale_generation_render_is_dropped`.
- ~~**Make state writes atomic**~~ — **done** 2026-08-19: `_save_last_page`
  writes a temp file and `os.replace`s it.

## Open

Two seams inside `PdfGridViewer` that a later agent could still take, in
increasing order of risk:

- **The TOC panel** (~226 lines). Narrow: only `doc`, `cells`, `page_count` and
  `jump_to_page` reach outside it. Would become a `TocPanel(QDockWidget)`; note
  `PageCell` calls `get_toc_text_highlights` from its paint path. The Y/U/I/O
  spec is well covered by `test_toc_fluid_nav_and_out`.
- **History.** Not encapsulated today: `_navigate_search` mutates `_history` and
  `_history_pos` directly to fold a whole search session into one Back target,
  coordinated through `_search_history_open`. Extracting it means designing that
  session contract, not moving code. `test_search_refine_keeps_one_back_target`
  was added to pin the fold first.
